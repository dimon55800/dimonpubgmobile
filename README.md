# Dimon PUBG Tool

Окремий офлайн Android-тренажер на Jetpack Compose:
- тренування швидкості наведення на мішені;
- демонстрація позначення ботів у тестовому полігоні;
- повзунок умовної віддачі;
- мінікарта тестового полігону.

Це не чит і не модифікація PUBG Mobile. Застосунок не читає пам'ять гри, не накладає ESP поверх PUBG і не обходить античит.

## Збірка
1. Розпакуйте архів.
2. Відкрийте папку `DimonPUBGTool` в Android Studio.
3. Дочекайтеся Gradle Sync.
4. Натисніть Build → Build APK(s).
5. APK буде в `app/build/outputs/apk/debug/`.

Потрібен Android Studio з Android SDK 35 та JDK 17.
